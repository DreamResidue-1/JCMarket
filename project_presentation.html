JCMarket — Online Marketplace

A full-stack e-commerce platform with chat-powered product search

Repository: ecommerce-backend
Main runtime: Node.js (recommend v22+)
Run locally: npm install → npm run dev

01
Project Objective

  • Provide REST APIs for products, cart, orders and users.
  • Support authentication (email / Google) and role-based access control.
  • Handle order persistence and shipping calculations.

02
Tech Stack

Node.js & Express
Sequelize (ORM)
MySQL / Postgres support
JWT Authentication
Nodemailer (emails)
sql.js (optional sqlite mode)

03
How I Built The Chatbot

  • Frontend: A React `ChatWidget` component (client/src/components/ChatWidget.js) toggles the UI, sends user messages to the backend, and stores a `threadId` to continue conversations.
  • Backend: Node/Express server (server/index.ts) exposes `POST /chat` and `POST /chat/:threadId` endpoints that call a LangChain agent.
  • Agent: Implemented in `agent.ts` using LangChain + Google Generative AI (Gemini). The agent uses a StateGraph workflow, a custom `item_lookup` tool, and `MongoDBSaver` to persist threads.
  • Search: Semantic vector search via `GoogleGenerativeAIEmbeddings` + `MongoDBAtlasVectorSearch` with a text-search fallback if no vectors match.
  • Resilience: Uses retry/backoff for rate limits, validation with `zod`, and graceful error responses to the frontend.
  • Env & Run: Requires `GOOGLE_API_KEY` and `MONGODB_ATLAS_URI`; start backend with `npm run dev` and open the client in a static server.

03
Project Structure

  • `routes/` — API endpoints (products, orders, auth, users)
  • `models/` — Sequelize models (Product, Order, User, CartItem)
  • `middleware/` — Auth, Google integration, helpers
  • `utils/` — Email, JWT helpers, session token logic

04
Setup & Run

  1. Install Node.js (v22+ recommended).
  2. Open the backend folder and run `npm install`.
  3. Start in dev mode: `npm run dev` (uses `nodemon` + `tsx`).
